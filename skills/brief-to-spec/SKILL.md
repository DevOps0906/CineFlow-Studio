---

## 입력
`templates/brief.template.md`를 채운 프로젝트 브리프, `docs/TEMPLATE_CATALOG.md`.

## 절차
1. 브랜드/전환 목표/분위기 분석
2. 사용 가능한 템플릿 2~3개 비교
3. 시그니처 모션 1개, 보조 모션 2~3개 선택
4. 에셋 라이선스 충족 여부 표시
5. `templates/spec.template.md` 형식으로 결과 작성
6. 승인 전에는 실제 구현을 시작하지 않음

## 완료 조건
섹션, 미디어, 모션, 반응형, 성능, 접근성, 수락 테스트가 모두 명시되어 있음.
