# PRD — CineFlow Studio

## 1. 제품 가설
디자인 명세 + 템플릿 + 모션 레시피 + 미디어 관리 + 에이전트 QA를 통합하면 고급 랜딩페이지의 반복 제작 시간이 줄어든다.

## 2. 사용자
- 1차: 내부 개발자·디자이너·웹 제작 대행
- 2차: 소규모 에이전시/콘텐츠 제작자
- 3차: 템플릿 생성 SaaS 사용자

## 3. MVP 범위
- 업종별 12종 템플릿; 우선 3종(T01 럭셔리, T04 건축, T03 AI SaaS)
- 20종 모션 레시피; 우선 8종
- brief → spec.md → 구현 → Playwright QA
- 에셋 권리정보 및 버전 관리
- GitHub PR 및 Vercel 프리뷰

## 4. 제외 범위
1차에서 결제·멀티테넌트·자체 AI 비디오 생성·대규모 마켓플레이스 제외.

## 5. 기능 요구사항
- FR01 템플릿 검색/선택/버전 고정
- FR02 업종·목표·CTA 기반 명세 생성
- FR03 애니메이션 및 reduced-motion fallback
- FR04 라이선스 체크가 완료된 에셋 선택
- FR05 화면별 시각 QA + 이슈 기록
- FR06 GitHub PR/프리뷰 내보내기

## 6. 비기능 요구사항
- 다양한 화면 폭에서 가로 넘침 없음
- 키보드 및 모션 감소 설정 대응
- 영상/3D 실패 시 포스터 이미지 표시
- 변경 이력, 파일 소유권, API 키 최소 권한

## 7. 성공 지표 (검증용 가설)
- 유료 파일럿 1~3건
- 템플릿 재사용률 50% 이상
- 반복 제작 시간 30% 이상 단축
- QA 1차 통과율 추적 및 개선

## 8. 게이트
브리프 승인 → 디자인 명세 승인 → 구현 리뷰 → QA 승인 → 배포

## 9. 성능·품질 예산 (MVP 기준값, 파일럿 후 조정)
| 항목 | 기준 |
|---|---|
| LCP (모바일 4G 에뮬레이션) | ≤ 2.5s |
| CLS | ≤ 0.1 |
| INP | ≤ 200ms |
| 초기 JS (gzip) | ≤ 200KB (3D 청크 제외, 지연 로드) |
| 히어로 영상 | ≤ 4MB (모바일 변형), 포스터 ≤ 150KB |
| GLB 모델 | ≤ 5MB, 뷰포트 진입 시 로드 |
| 콘솔 에러 / 404 | 0건 |
| 가로 넘침 | 390·768·1440px에서 0건 |
| Lighthouse 접근성 | ≥ 95 |
| 애니메이션 | transform/opacity 위주, 언마운트 시 cleanup 필수 |

## 10. MVP 우선 모션 8종
M01 Blur-in, M02 Split reveal, M03 Parallax, M04 Pinned story, M05 Seamless video loop, M06 Media reveal, M07 Magnetic CTA, M08 Model reveal. 상세는 docs/MOTION_CATALOG.md.
