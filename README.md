# CineFlow Studio Planning Kit

MotionSites 워크플로우를 참고해 설계한 독립적인 웹 템플릿 제작 시스템의 초기 문서 패키지.

## 순서
1. `docs/PRD.md`로 MVP 범위·성공 기준 확정
2. `templates/brief.template.md` 작성
3. `templates/spec.template.md`로 화면/모션/에셋 명세 확정
4. `AGENTS.md` 기준으로 Claude Code 및 Codex 작업 분담
5. `templates/qa-report.template.md`와 승인 게이트로 검증

## 주의
- 코드는 포함하지 않음: 설계·프로젝트 운영용 문서 템플릿.
- MotionSites 예제 프롬프트·미디어는 저작권 대상. 무단 번들/재배포 금지.
- 아키텍처와 가격은 CineFlow 신규 제안이며 공식 MotionSites 기능이 아님.
