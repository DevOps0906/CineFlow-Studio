## 범위
- `/` 대시보드: KPI 4종, 템플릿 현황(12), 승인 게이트, 최근 QA, MVP 모션 8종
- 좌측 GNB: 대시보드 + 카테고리 12종(T01~T12, 상태 점 표시). 1024px 미만에서는 상단 바 + 토글 메뉴
- `/category/[t01..t12]`: 카테고리별 페이지 (요약, 히어로, 진행 상태, 섹션 구성, 사용 모션, 이전/다음)
- 데이터: `lib/data.ts`는 정적 카탈로그(이름, 히어로, 제안 모션). 상태·모션 구현·승인 게이트·QA는 `lib/registry.ts`가 `projects/*`(spec.md, brief.md, qa-report.md, site/)를 빌드 시 읽어 집계. DB 연동은 범위 밖
